# מדריך התקנה ושימוש - מערכת דיווח פניות לקוח (PWA)

מערכת זו פועלת כאפליקציית Web עצמאית (PWA). היא פועלת באופן מלא במצב אופליין (ללא קליטה סלולרית או אינטרנט), שומרת את הנתונים בזיכרון המכשיר, ומאפשרת ייצוא לקובץ Excel בכל עת.

---

## 1. איך מריצים את הפרויקט ב-Visual Studio Code?

1. התקן ב-VS Code את התוסף: **Live Server** (של Ritwick Dey).
2. פתח את תיקיית הפרויקט ב-VS Code.
3. לחץ קליק ימני על הקובץ `index.html` ובחר: **Open with Live Server**.
4. האתר ייפתח בדפדפן בכתובת כגון: `http://127.0.0.1:5500/index.html`.

---

## 2. התקנה באייפון (iOS)

> באייפון יש להשתמש בדפדפן **Safari** בלבד לצורך התקנה למסך הבית.

1. פתח את הקישור לאפליקציה בדפדפן **Safari**.
2. לחץ על כפתור השיתוף בתחתית המסך (הריבוע עם החץ הפונה מעלה ⬆️).
3. גלול בתפריט למטה ובחר באפשרות **"הוסף למסך הבית"** (Add to Home Screen).
4. לחץ על **"הוסף"** (Add) בפינה השמאלית/ימנית העליונה.
5. כעת יופיע אייקון של האפליקציה על גבי מסך הבית. כניסה דרכו תפתח מסך מלא, ללא שורת כתובת של דפדפן, ובזמינות מלאה גם במצב טיסה.

---

## 3. התקנה באנדרואיד (Android)

1. פתח את הקישור לאפליקציה בדפדפן **Google Chrome**.
2. לעיתים קופצת הודעה אוטומטית בתחתית המסך: **"הוסף את 'פניות לקוח' למסך הבית"**.
3. אם ההודעה אינה מופיעה:
   - לחץ על תפריט 3 הנקודות (⋮) בצד שמאל/ימין למעלה.
   - בחר באפשרות **"התקנת אפליקציה"** (או "הוספה למסך הבית").
4. אשר את ההתקנה. האפליקציה תתווסף למסך היישומים של הטלפון.

---

## 4. מדריך שימוש שוטף

### א. כניסה ראשונה:
- בהפעלה הראשונה יוצג מסך להזנת **שם העובד המדווח**. השם נשמר בזיכרון המכשיר.

### ב. דיווח פנייה חדשה:
1. שדות התאריך והשעה מתמלאים אוטומטית בזמן הנוכחי.
2. ניתן לשנות לתאריכי ושעות עבר; המערכת **חוסמת** בחירת זמנים עתידיים.
3. ממלאים את תיאור הפנייה.
4. בוחרים האם נדרש המשך טיפול:
   - אם נבחר **"כן"**, ייפתח שדה נוסף לכתיבת תוכן המשימה.
5. לוחצים על **"שמור דיווח"**.

### ג. תפריט אפשרויות (3 קווים למעלה מימין):
- **דיווח פנייה חדשה:** פותח טופס נקי.
- **כל הדיווחים ואקסל:** מציג את רשימת כל הפניות שנשמרו על פי סדר כרונולוגי יורד.
- **החלפת משתמש:** מאפשר לשנות את שם העובד שממלא את הדיווחים במכשיר.

### ד. צפייה, עריכה וייצוא:
- **לחיצה על שורת דיווח:** פותחת את פרטי המקרה כשהם **נעולים לעריכה** לצורך קריאה נוחה.
- **עריכה:** לחיצה על כפתור "ערוך דיווח" מאפשרת לעדכן את השדות ולשמור שוב.
